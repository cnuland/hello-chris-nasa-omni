## What changed, in the order it happened
1. **Gemma 4 replaced Qwen2.5-Omni.**
   - On 8 NASA windows Gemma gave 0 whole-frame junk boxes out of 50 objects; Qwen gave 35 of 73.
   - Gemma names real ISS hardware (hatches, EXPRESS racks, storage bags).
   - On T4, Gemma's image path overflows fp16 (the T4 has no bf16), so it runs **fp32** at about 25–60 s per window.
     Frames are sampled every 30 s, per your "lower rate is fine". On the GB10, bf16 or FP8 removes this.
   - **Cosmos Reason is post-trained from Qwen-VL**, so it may not count as US-origin. I didn't use it.
     **Nemotron 3 Nano Omni** (NVIDIA-built) is the GB10 alternative; see `research/07-us-models.md`.
2. **Playwright reviewer, 4 rounds.** Each round's findings became spec changes, failing tests, fixes and a redeploy.
   Main fixes:
   - duplicate cards show the candidates side by side, with ranked reasons, and merge can be undone;
   - person tracks show appearance only ("Person: black shirt, grey pants");
   - event wording reads naturally;
   - layout works at 1024 px;
   - chat answers grounded follow-ups, gives exact counts, and pages long lists.
3. **Real-video eval** (`make eval-real`): scores perception against NASA's own caption timeline. It showed that
   location misses were all "unresolved", never a wrong module. Module aliases plus a scene-summary fallback took it
   from 0.391 to 0.750.
4. **People:**
   - Gemma reports people separately, so person tracks had silently dropped to 0. Fixed.
   - Cross-module continuity brought the tracks for the real tour sequence down from 37 to 22.
5. **Privacy.** Each case was found live, fixed under TDD and verified:
   - **Sleeping crew:** windows that show sleeping crew become private, so no frames, text or reviews are stored. A
     30 s hold covers the overlapping next window.
   - **Private text:** private windows' text is redacted, and 8 old rows were redacted by a migration.
   - **P1, a face crop:** an object box ("window") cropped a crew member's face. I purged it with an audit row,
     paused perception, and shipped a guard (no crop that overlaps a person, checked in both perception and the API)
     before resuming.
6. **Demo quality:** station structure (hatches, windows, handles) no longer floods the unknown queue (89% filtered,
   0 catalog items lost). The duplicate review supports merge and undo.
7. **Boxes:** Gemma's boxes were being thrown away, because it answers in its native `[y1,x1,y2,x2]` 0–1000 format.
   The order was verified by drawing both readings on real frames, and 141 of 142 boxes now survive. Unknowns get
   OWLv2 boxes from their own label (the Kibo orange sphere was found at 0.60). Every crop still goes through the
   person-overlap guard.
8. **Re-ID and locations:** a laptop no longer "teleports" between modules on a weak match. A segment-only sighting
   no longer downgrades a module location. "Who was in the Cupola?" counts everyone seen there.

## 5-minute demo script
1. **Inventory** (`/`): filter Location = Cupola, then search "laptop", then sort by last seen. Point out the UTC
   times, module codes and "Last handled".
2. **Item detail:** open a laptop. Show the frame with its detector box, the activity, the history, and "Location set
   by". Edit its location as operator "demo".
3. **Review** (`/review`): duplicates show candidates side by side with reasons. Merge, then Undo. Unknowns: classify
   one, or use "Not inventory".
4. **Overview:** person tracks by module and recent events in plain English.
5. **Chat:** "Where is the laptop right now?", "Who used the drill?", "How many people have been seen today, and
   where?", "What changed in the last hour?" Each answer has citations, and you can click through to the items.
6. **Privacy talking point:** sleeping-crew windows leave no media and no searchable text, and there are never face
   crops (verified in RustFS).
